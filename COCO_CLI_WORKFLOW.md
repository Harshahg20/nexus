# NEXUS — Built With Snowflake CoCo CLI

This document shows how **Snowflake CoCo CLI** (the terminal-native AI coding agent) was used throughout the NEXUS development workflow. CoCo CLI understands your Snowflake schema, RBAC, and data catalog to generate production-ready SQL, pipelines, and agents from natural language.

## Setup

```bash
# Install Snowflake CLI
pip install snowflake-cli-labs

# Connect to NEXUS account
snow connection add \
  --connection-name nexus \
  --account EB70963.ap-northeast-1.aws \
  --user HGHARSHA20 \
  --private-key-path ~/.ssh/snowflake_key.p8 \
  --database NEXUS_DB \
  --warehouse COMPUTE_WH \
  --role ACCOUNTADMIN

# Verify connection
snow connection test --connection-name nexus
```

## Live CoCo CLI Commands

```bash
# Query the NEXUS supply chain via Cortex
snow cortex complete \
  --query "What is the revenue impact if SUP-001 is unavailable for 14 days?" \
  --model snowflake-arctic \
  --connection nexus

# Generate a new scenario extension
snow coco "Add a tariff shock scenario that increases landed cost by 25% and recalculates at-risk revenue across all active orders"

# Deploy the Streamlit app via CLI
snow streamlit deploy --connection nexus

# Run validation suite
snow sql -f snowflake/015_extended_tests.sql --connection nexus
```

## Why CoCo CLI Was Central

CoCo CLI was not just a helper — it was the **primary development interface** for NEXUS:

1. **Schema-aware generation**: CoCo CLI introspected the existing schema before generating each new SQL file, ensuring FK consistency across all 15 migration files.
2. **Iterative refinement**: The scenario engine SQL went through 3 CoCo CLI iterations before the priority-allocation logic passed all 33 test assertions.
3. **Agent scaffolding**: The Cortex Agent tool configuration (`DATA_AGENT_RUN` with semantic view binding) was generated entirely from a single CoCo CLI prompt.
4. **Test-driven workflow**: CoCo CLI generated test assertions *after* each component, creating a test-first discipline across the entire SQL layer.
