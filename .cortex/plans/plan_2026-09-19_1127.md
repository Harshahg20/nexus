### Execution Order (dependency-aware)

#### Step 1 — `001_schema.sql`
- **Creates:** Database `NEXUS_DB`; schemas `RAW`, `SEMANTIC`, `SCENARIOS`, `ANALYTICS`; 12 tables (`RAW.SUPPLIERS`, `RAW.PARTS`, `RAW.PLANTS`, `RAW.INVENTORY`, `RAW.PORTS`, `RAW.SHIPMENTS`, `RAW.PRODUCTS`, `RAW.ORDERS`, `RAW.CUSTOMERS`, `SCENARIOS.SCENARIO_DEFINITIONS`, `SCENARIOS.SCENARIO_IMPACTS`, `SCENARIOS.MITIGATION_OPTIONS`)
- **Prerequisites:** None (foundation script)
- **Rerunnable:** Yes — all `CREATE OR REPLACE` / `CREATE IF NOT EXISTS`
- **Caveats:** Drops and recreates all RAW tables (losing data). Must run before any seed or view script.
- **Validation:** `SELECT COUNT(*) FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_CATALOG='NEXUS_DB';` — expect 12

#### Step 2 — `002_seed_data.sql`
- **Creates:** Seed rows in all 9 RAW entity tables (SUPPLIERS through ORDERS/CUSTOMERS)
- **Prerequisites:** 001 (tables must exist)
- **Rerunnable:** Yes — TRUNCATEs each table before inserting
- **Caveats:** Does NOT seed `PRODUCT_PARTS` or `SUPPLIER_PARTS` (those come from 003 and 007). Does NOT seed SCENARIOS tables.
- **Validation:**
  ```sql
  SELECT 'SUPPLIERS' AS t, COUNT(*) AS n FROM NEXUS_DB.RAW.SUPPLIERS
  UNION ALL SELECT 'PARTS', COUNT(*) FROM NEXUS_DB.RAW.PARTS
  UNION ALL SELECT 'PLANTS', COUNT(*) FROM NEXUS_DB.RAW.PLANTS
  UNION ALL SELECT 'INVENTORY', COUNT(*) FROM NEXUS_DB.RAW.INVENTORY
  UNION ALL SELECT 'PORTS', COUNT(*) FROM NEXUS_DB.RAW.PORTS
  UNION ALL SELECT 'SHIPMENTS', COUNT(*) FROM NEXUS_DB.RAW.SHIPMENTS
  UNION ALL SELECT 'PRODUCTS', COUNT(*) FROM NEXUS_DB.RAW.PRODUCTS
  UNION ALL SELECT 'ORDERS', COUNT(*) FROM NEXUS_DB.RAW.ORDERS
  UNION ALL SELECT 'CUSTOMERS', COUNT(*) FROM NEXUS_DB.RAW.CUSTOMERS;
  ```
  Expected: SUPPLIERS=10, PARTS=20, PLANTS=5, INVENTORY=20, PORTS=5, SHIPMENTS=15, PRODUCTS=6, ORDERS=20, CUSTOMERS=8
